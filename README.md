# weavestream

Weave structured JSON stream payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/weavestream/

## Install / run

```bash
git clone https://github.com/theworker02/weavestream.git
cd weavestream
node src/cli.js
node --test
```
